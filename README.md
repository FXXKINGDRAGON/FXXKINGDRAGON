# FXXKINGDRAGON

A minimal Python project scaffold.

## Requirements

- Python 3.10 or newer

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

## Test

```bash
pytest
```
